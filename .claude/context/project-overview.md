# Laboon — Vision produit

## Le produit
Laboon est une application de **mise en relation entre musiciens** (matchmaking
musical) : trouver des partenaires de jeu, monter un groupe, rencontrer d'autres
musiciens selon l'instrument, le style, le niveau, la localisation, etc.

## Objectif de la landing page
La landing page n'est **pas** l'application. Son seul but avant le lancement :
1. Présenter le concept de manière attractive.
2. **Récolter des adresses emails** pour deux usages :
   - être prévenu·e du **lancement**,
   - rejoindre la **beta** (testeurs).

Un même inscrit peut cocher l'une, l'autre, ou les deux options.

## Public cible
Musiciens amateurs et confirmés cherchant à jouer/collaborer avec d'autres.

## Indicateurs de succès
- Nombre d'emails collectés (lancement / beta).
- Taux de conversion visiteur → inscrit.

## Ton & image
Moderne, sombre, énergique, communautaire. Donner envie de faire partie de
l'aventure dès le début.
